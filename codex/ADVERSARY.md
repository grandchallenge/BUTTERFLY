# Adversary Prompt

Attempt to invalidate every closure and performance claim.

Construct:

- random dense operators;
- operators with one hidden high-energy direction;
- favorable training blocks and unfavorable held-out blocks;
- permutations that create false closure on sampled partitions;
- ill-conditioned factor products;
- rapidly state-varying conditional operators;
- accelerator sizes where sparse execution loses to dense;
- cases where compilation never amortizes.

A result passes only when its scope is narrowed to exclude demonstrated failures or the implementation is corrected.
