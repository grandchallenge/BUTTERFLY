# Work Package Checklist

- [ ] Scope and exclusions are explicit.
- [ ] Public contracts are identified.
- [ ] Reference implementation exists.
- [ ] Unit tests pass.
- [ ] Numerical tests pass.
- [ ] Adjoint tests pass or adjoint is explicitly unavailable.
- [ ] Random dense negative control is included.
- [ ] Failure and rejection behavior is tested.
- [ ] Benchmark configuration is checked in.
- [ ] Compilation and runtime costs are separated.
- [ ] Artifact paths and seeds are recorded.
- [ ] Documentation and terminology are synchronized.
- [ ] Agent review ledger is complete.
- [ ] Referee acceptance criteria are satisfied.
